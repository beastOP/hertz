# Hertz

Video calls for Android and the web.

[Open Hertz](https://hertz-beastop.vercel.app) · [Android releases](https://github.com/beastOP/hertz/releases)

Install the APK from a release on Android 7 or later. Android may ask you to allow installation from your browser. Friends can join the same invitation link in a web browser.

The first public build uses a new release signing key. If the local USB prototype is installed, Android requires removing that debug build before installing the release. This clears its saved name and server setting.

Calls must stay in the foreground. Video adjusts to connection quality and can fall back to audio. Calls still require a working internet connection.

This repository distributes the Android releases. Application source and signing credentials are not included.
